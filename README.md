# Sleep & Study Efficiency Analyzer

This project analyzes the relationship between sleep habits and student learning efficiency. The app uses Python and Streamlit to explore how sleep hours, sleep quality, study hours, and screen time before bed may affect study efficiency.

## Features

- Generates or uploads student study data
- Calculates average sleep hours, study hours, screen time, and efficiency score
- Shows correlation between variables
- Creates data visualizations
- Classifies study efficiency as High, Medium, or Low
- Gives personalized study recommendations
- Allows users to download analyzed results

## Tools Used

- Python
- Streamlit
- pandas
- NumPy
- Matplotlib

pip install -r requirements.txt
